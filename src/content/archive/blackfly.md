## Better tools for an experiment

As an undergraduate researcher in Spencer Lake’s Musculoskeletal Soft Tissue Lab at Washington University in St. Louis, I developed a graphical interface for a FLIR Blackfly polarized-light camera.

The C++ backend communicates with the camera, while the Qt interface displays three live camera views and gives researchers control during an experiment. The interface supported more precise and convenient reflectance-mode quantitative polarized-light imaging. I also tested the camera against an older custom-built system.

[Explore the source code on GitHub](https://github.com/ejmeitz/GUI).
